# Responsive Fashion Landing Page 👗

A fashion-inspired product landing page built with HTML and CSS, with a focus on responsive design.

## About the Project

This project presents a minimalist fashion product page featuring bold typography, navigation links, product information, and a large fashion image.

## Built With

- HTML5
- CSS3
- Flexbox
- Media Queries
- Remix Icon
- Gilroy Font

## Features

- Minimal navigation bar
- Large product heading
- Product description and information links
- Hover effects with arrow icons
- Fashion photography section
- Mobile layout using CSS media queries

## What I Learned

- Responsive design using `@media`
- Adjusting font sizes for mobile screens
- Changing Flexbox direction for smaller screens
- Using viewport units such as `vw`
- Creating interactive hover effects

## Future Improvements

- Improve tablet responsiveness
- Refine mobile spacing and typography
- Optimize images for faster loading
- Deploy using GitHub Pages
